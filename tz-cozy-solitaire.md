# ТЗ: «Cozy Solitaire» — карточный казуал (Klondike) с мета-обвязкой «декор/ремонт комнат»

Версия 1.0 · 23.09.2026 · Целевая платформа: CrazyGames (волна 1), далее Poki/GameMonetize/GameDistribution/GamePix (неэксклюзивно)

---

## 1. Продукт и цель

Одностраничная HTML5-игра: классический пасьянс Klondike + мета-прогрессия «обустраиваем дом» (покупка мебели и декора за игровые монеты). Модель-референс: Solitaire Home Story (1 млн+ плеев на CrazyGames при всего 45 конкурентах в категории Card — замер 23.09.2026).

Цель продукта: удержание (retention) и длина сессии — от них зависит рекламная выручка. Игра бесплатная, монетизация только через рекламу платформы (SDK), без IAP.

Аудитория: казуальная, преимущественно женская 25+, десктоп + мобильный веб. Рейтинг контента: PEGI 12-совместимо (без насилия, без нецензурного, без азартных механик на деньги).

Критерии успеха Basic Launch (CrazyGames): ≥500 плеев за 7 дней, средний playtime ≥5 мин, возврат ≥15% next-day.

## 2. Ядро геймплея: Klondike

### 2.1 Правила
- Стандартная колода 52 карты, 4 масти.
- 7 столбцов tableau: в i-м столбце i карт, верхняя открыта.
- Stock (запас) и waste (сброс); 4 foundation (базы) — собираем по мастям от туза до короля.
- Перемещения в tableau: по убыванию, чередуя цвет; на пустой столбец — только король (или последность во главе с королём); группы карт перетаскиваются целиком, если валидны.
- Два режима сложности (выбор в меню перед раздачей):
  - **Draw 1** — из запаса по одной карте, бесконечные проходы по запасу. Награда за победу: 100 монет.
  - **Draw 3** — по три карты, до 3 проходов по запасу. Награда: 150 монет.
- Победа: все карты в foundation. Поражения как сущности нет — игрок может выйти или нажать «Новая раздача».

### 2.2 Генерация раскладов
- Расклады генерируются процедурно с seed; seed сохраняется в состоянии игры.
- Обязательно: только решаемые расклады (генератор проверяет решаемость симуляцией/бэктрекингом при генерации; кэш валидных seeds). Недопустимо выдавать нерешаемую раздачу.

### 2.3 Управление
- Десктоп: drag-and-drop (pointer events), одинарный клик = автоход на foundation, двойной клик по карте в tableau/waste = отправить на foundation.
- Мобильный веб: тап-тап (выбрал карту → выбрал цель) + drag; touch-цели ≥44px.
- Автосбор: при возможности — кнопка «Auto» достраивает все foundation до победы (использовать только за rewarded-рекламу или бесплатно при полной открытости tableau — решение: бесплатно, если все карты открыты).

### 2.4 Помощники
- **Undo** — отмена хода, бесплатно первые 5 за раздачу, далее за монеты (20 монет) или rewarded-видео (безлимит undo на текущую раздачу).
- **Hint (подсказка)** — подсветка лучшего хода: бесплатно 3 за раздачу, далее rewarded-видео (3 подсказки) или 50 монет.
- Таймер раздачи и счётчик ходов отображаются (для статистики и ощущения прогресса).

## 3. Мета: декор и ремонт комнат

### 3.1 Цикл
Победа в раскладе → монеты → покупка предметов декора/мебели → комната меняется визуально → открывается следующая комната/задача.

### 3.2 Комнаты
- Стартовая комната: **Гостиная** (открыта сразу, бесплатна).
- Последовательность разблокировки: Гостиная → Кухня → Спальня → Сад → Кабинет (5 комнат в v1.0).
- Разблокировка комнаты стоит монет (см. экономику) и требует завершения предыдущей комнаты ≥60% предметов.

### 3.3 Предметы
- В каждой комнате 8–12 предметов: мебель (диван, стол, лампа…), декор (картины, растения, ковры), «отделка» (цвет стен, пол) — 2–3 варианта на слот.
- Каждый предмет имеет цену и визуальный слой; покупка мгновенно отображается в сцене комнаты.
- Предметы в рамках комнаты делятся на обычные и «премиум» (в 2–3 раза дороже, заметнее визуально) — цель для долгосрочного копления.

### 3.4 Задачи (квесты)
- Лёгкий слой квестов: «Выиграй 3 раздачи», «Купи 2 предмета», «Собери комбо x3» — награда монетами/предметом.
- Квесты обновляются ежедневно (3 активных), дают причину вернуться (retention-крючок D1/D7).

### 3.5 Сцена комнаты
- Экран «Дом» — отдельная сцена: изометрическая или фронтальная комната, сетка слотов предметов, кнопки покупки/выбора варианта отделки.
- Переходы Дом ↔ Игра в 1 тап из любого места (требование CrazyGames: ≤1 клик до геймплея для нового пользователя).

## 4. Экономика (стартовые числа, балансируются после теста)

| Источник/расход | Значение |
|---|---|
| Победа Draw 1 | +100 монет |
| Победа Draw 3 | +150 монет |
| Победа без подсказок и undo | +25% бонус |
| Комбо (победы подряд в одну сессию) | x2/x3/x4: +10/+25/+50% к награде |
| Ежедневный бонус (день 1→7) | 50/75/100/150/200/300/500 |
| Квесты | 30–150 за квест |
| Rewarded-видео «удвоить награду» | x2 к награде за победу |
| Разблокировка комнаты | 1500 / 3000 / 5000 / 8000 (Кухня/Спальня/Сад/Кабинет) |
| Обычный предмет | 100–500 |
| Премиум-предмет | 800–2000 |
| Отделка (стены/пол) | 200–600 за вариант |
| Undo сверх лимита | 20 монет |
| Hint сверх лимита | 50 монет |

Темп: при ~4 победах в сессию (20–30 мин) игрок зарабатывает ~500–700 монет/сессию; полная обстановка одной комнаты ≈ 5–8 сессий. Целевой lifetime v1.0 ≈ 30–40 сессий.

## 5. Монетизация (только реклама, через SDK платформы)

### 5.1 Rewarded video (добровольное)
- Удвоить награду за победу (окно 10 сек после победы).
- Безлимит undo на раздачу.
- 3 подсказки.
- +250 монет раз в 4 часа («копилка»).

### 5.2 Interstitial
- Только после победы в раскладе, не чаще 1 раза в 4 минуты, пропустить первые 2 победы новой сессии.
- Запрещено: interstitial во время раздачи, при входе/выходе из игры, между сценами Дома.

### 5.3 Banner
- Не используется в v1.0 (портит UX казуалки, малый доход).

### 5.4 SDK-события (обязательно для CrazyGames)
- `gameplayStart()` — первый экран раздачи показан.
- `gameplayStop()` — уход из раздачи/победа/выход.
- `gameLoadingStart/gameLoadingFinished`.
- Rewarded/interstitial — только через методы SDK платформы (CrazyGames SDK; для GameMonetize/GameDistribution — их SDK в отдельных сборках).
- Архитектура: единый интерфейс `AdProvider` с реализациями `CrazyGamesProvider`, `GameMonetizeProvider`, `LocalProvider` (без рекламы для разработки), сборка под платформу через флаг/конфиг.

### 6.1 Разрешения и layout
- Базовый дизайн 1280×720, scale mode FIT + safe-area для notch.
- Portrait-раскладка мобильного: tableau компактный, верхняя панель (stock/foundation) в одну строку.

### 6.2 Сохранения
- v1.0: localStorage (профиль: монеты, купленные предметы, прогресс комнат, квесты, ежедневный бонус, статистика побед, текущая раздача: seed + история ходов для undo + состояние tableau).
- Схема сохранения версионируется (`saveVersion`), миграции обязательны.
- Позже: облачные сохранения через SDK платформы (CrazyGames CloudSave) — предусмотреть слой `SaveProvider`.

### 6.3 Производительность
- Drag-drop карт без лагов на 60fps (объекты — пул спрайтов, без пересоздания).
- Все анимации — tween ≤300ms; частицы на победу — ограниченный пул.
- Аудио: Web Audio, ≤5 одновременных голосов.

## 7. Экраны и поток

1. **Загрузка** — прогресс-бар, ≤5 сек, без кликов.
2. **Первый экран = раздача** (требование ≤1 клик): сразу идёт новая раздача Draw 1; кнопка «Дом» в углу.
3. **Экран раздачи** — tableau, stock/waste, foundation, панель: Undo, Hint, Auto, Новая раздача, Дом, монеты, пауза (звук/настройки).
4. **Экран победы** — награда, комбо, кнопка rewarded «x2», «Следующая раздача», «В Дом» (interstitial показывается здесь по правилам 5.2).
5. **Дом** — комната, слоты предметов, магазин, квесты, переключатель комнат, кнопка «Играть».
6. **Настройки** — звук/музыка вкл/выкл, сброс прогресса (с подтверждением), язык (EN v1.0).

## 10. Этапы разработки и приёмка

### M1 — Ядро пасьянса (без мета, без SDK)
Готово когда: валидная генерация решаемых раскладов; drag-drop + тап-управление на десктопе и мобильном; undo/hint работают; победа фиксируется; 60fps на среднем телефоне. Тест: 100 сыгранных раздач без ошибок; проверка решаемости на 1000 сгенерированных seeds = 100%.

### M2 — Мета и экономика
Готово когда: монеты начисляются по таблице §4; 5 комнат, покупка предметов мгновенно меняет сцену; квесты и ежедневный бонус работают; сохранение/загрузка корректны после перезагрузки страницы; миграция saveVersion работает.

### M3 — Платформа: SDK, реклама, аналитика
Готово когда: сборка под CrazyGames с SDK (gameplayStart/Stop, loading-события); rewarded и interstitial по правилам §5.2; LocalProvider для dev; initial download ≤8MB; загрузка до геймплея ≤5 сек; ≤1 клик от загрузки до раздачи. Тест: полный прогон в Chrome/Edge/Safari, mobile Chrome (Android) и Safari (iOS).

### M4 — Полировка и подача
Звук, победа-эффекты, туториал первой раздачи (2 стрелки-подсказки, без модалок), иконки/скриншоты для страницы портала (512×512 иконка, 3 скриншота 1280×720), описание EN. Подача на Basic Launch.

### Out of scope v1.0
IAP/платный контент, мультиплеер, серверная часть, облачные сохранения, лидерборды, сезоны/ивенты, более 5 комнат, Spider/TriPeaks-режимы.

## 11. Требования к реализации (для разработчика/GLM)

- TypeScript, Phaser 3.8x, сборка Vite; структура: `/src/core` (логика пасьянса — чистые функции, без Phaser), `/src/scenes`, `/src/meta`, `/src/platform` (AdProvider/SaveProvider), `/assets`.
- Логика Klondike — отдельный модуль без зависимостей от движка (тестируемость: unit-тесты на правила и генератор решаемости, Vitest).
- Детерминированная генерация по seed (mulberry32 или аналог).
- Никаких внешних запросов/трекеров кроме SDK платформы (Poki/CrazyGames запрещают стороннюю аналитику; GameMonetize разрешает шире — держать всё за флагом сборки).
- Код без «сюрпризов»: все магические числа экономики — в одном конфиге `economy.ts`.

## 13. Отклонения от спеки (зафиксированы по ходу реализации)

- **Draw-3: проходы по колоде не ограничены.** Спека п.2 предполагала лимит проходов; решено дать бесконечные проходы без штрафов — проще для казуальной аудитории и убирает тупиковые состояния. Балансируется после теста (п.10).
- **Phaser-чанк 339,7 kB gzip вместо цели ≤250 kB.** npm-пакет Phaser не содержит tree-shakeable исходников (файлы `src/` — конкатенационные, не ES-модули) и не даёт кастомную сборку офлайн. Реальные лимиты порталов (CrazyGames: initial ≤50 MB, total ≤250 MB, ≤1500 файлов) выполнены с ~30-кратным запасом; гейм-чанк 9,2 kB gzip (цель ≤20 kB) выполнен. Вернуться к кастомной сборке Phaser, если портал ужесточит требования.
- **Портретная ориентация проверена расчётом метрик, а не реальным ресайзом вьюпорта** (синтетический ресайз в headless-окружении не обновляет буфер canvas). Проверка на реальном устройстве — в этапе M4.
- **Прогресс комнаты для разблокировки следующей (§3.2, ≥60%)** считается как доля купленных+бесплатных вариантов от ВСЕХ вариантов комнаты (living: 23 варианта → нужно владеть 14). Бесплатные варианты дают 8/23 ≈ 35%, так что гейт реально работает и не открывается «сразу за монеты».
- **Имена loading-событий SDK (§5.4):** в актуальном CrazyGames HTML5 SDK v2 (docs.crazygames.com/sdk/html5-v2, проверено 23.09.2026) методы называются `game.sdkGameLoadingStart()/sdkGameLoadingStop()`, а interstitial запрашивается как `ad.requestAd('midgame', …)`. В коде CrazyGamesProvider маппит loadingStart/loadingFinished и showInterstitial на эти имена. Init не нужен («You don't need to call init() anymore»).

## 14. Тесты (как запустить)

- `npm test` — 45 юнит-тестов на `node:test` + `tsx`, без браузера и без новых зависимостей:
  - `tests/core.test.ts` — RNG, форма раздачи (52 уникальные карты, 1..7, одна открытая на столбик), детерминизм по сиду, набор/сброс колоды (draw-1 и draw-3, лимит проходов), правила фундамента/столов, связки карт, undo, победа.
  - `tests/meta.test.ts` — экономика и профиль: стартовый профиль, монеты/clamping, `buyVariant` (invalid/poor/bought/selected), гейт разблокировки 60%, дейли-стрик и таблица бонусов, копилка и кулдаун, квесты (сид дня, кэш по target, двойной клейм запрет), формула награды за победу, миграция сейва v0 и `reset()`.
  - `tests/data.test.ts` — целостность данных: цены комнат возрастают, бесплатный вариант всегда первый и цены по возрастанию, slot-координаты внутри комнаты, у каждого варианта 2+ HEX-цвета и форма из списка тех 13, что реально рисует `HomeScene.drawArt`, слои мебели выше стен; строки: каждая `t('key')` из `src/` существует в `strings/en.json`, мёртвых ключей нет, все плейсхолдеры подставляются.
- `npm run test:solver` — тяжёлый смоук (`src/core/smoke.ts`): 100 раздач draw-1 и 30 раздач draw-3, каждая проверена солвером и проиграна до победы (≈30 с).
- `npm run typecheck` — `tsc --noEmit` покрывает и `src`, и `tests`.
